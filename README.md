# CSGA Platform Source

This is the complete source code for the CSGA (Certified Secure AI Professional) Platform - a comprehensive training, certification, and governance system for artificial intelligence safety and compliance.

## Project Overview

The CSGA Platform is built with React/TypeScript and provides:

- **Training & Learning**: Comprehensive courses on AI safety, compliance, and governance frameworks
- **Certification**: Industry-recognized certifications including CEASIA and CASA
- **Council System**: Byzantine Consensus-based governance for platform decisions
- **Watchdog Program**: Incident reporting and AI safety monitoring
- **Compliance**: Multi-jurisdictional AI regulatory compliance (EU AI Act, UK, Canada, China, Australia)
- **Community**: User interactions, ratings, feedback, and social features
- **Analytics & Tools**: Dashboard, API management, reporting, and analytics

## Directory Structure

- **components/** - React UI components organized by feature/domain
- **data/** - Module content and course data
- **api/** - Backend services, routes, and API schemas
- **config/** - Configuration files
- **tests/** - Test specifications and unit tests
- **assets/** - Static files (images, styles, documents)
- **scripts/** - Utility scripts
- **docs/** - Documentation and guides

## Technology Stack

- React with TypeScript
- Vite for build tooling
- TailwindCSS for styling
- E2E testing with Cypress
